## [1.0.0] - 2026-01-14

### Added
- Initial repository structure
- Comprehensive README.md with phenomenon documentation
- api.json following Wyrdness schema v1.0.0
- SOURCES.md bibliography
- Issue templates for sighting reports, corrections, and source additions
- Pull request template

### Data Included
- Basic phenomenon metadata and classification (DEMON_ANGEL)
- Physical characteristics and manifestation abilities
- Geographic distribution (global, all major religions)
- Historical timeline (~3000 BCE-present)
- 3 notable historical cases (Loudun 1634, Anneliese Michel 1976, Roland Doe 1949)
- Demon hierarchies (Christian, Islamic, Jewish, Hindu, Buddhist)
- Evidence catalog including possession cases
- Theories (theological, psychological, neurological, sociological, skeptical)
- Cultural significance across religions
- Exorcism practices and protection methods
- Cultural and religious sensitivity guidelines
